# README project overview

One-paragraph summary of the obsidian-react repository from the root README.

## Key points

- **Purpose:** Static Next.js site that displays Obsidian notes with Bases (YAML frontmatter) properties as badges.
- **User path:** Upload `vault.zip` in the browser — no setup required for non-developers.
- **Developer path:** Sync from local Obsidian vault → `/vault` → push → Netlify auto-rebuild.
- **Quality gate:** TDD with ~47 automated tests (Jest + Python sync); deploy blocked if tests fail.
- **Stack:** Next.js 15, React 18, gray-matter, adm-zip, formidable; static export to `out/`.

## Detailed notes

### Project structure

| Path | Role |
|------|------|
| `lib/` | Business logic — `noteReader.ts`, `notes.ts` (tested) |
| `app/` | UI — `page.tsx`, `NoteCard.tsx` (tested) |
| `vault/` | Markdown at build time (gitignored; generated by sync or import) |
| `sync/` | Python Obsidian → vault sync (12 tests) |
| `jest.config.js` | Jest configuration |
| `netlify.toml` | Deploy: `npm run build:netlify`, publish `out/` |

### Commands (from README)

```bash
npm install
npm run dev          # localhost:3000
npm test             # watch mode
npm run test:ci      # CI once
npm run build        # test:all + next build
npm run sync         # Obsidian → vault
```

### Autonomous operation

Static site — no server, database, or maintenance after deploy. Netlify rebuilds on git push; tests run before every build.
